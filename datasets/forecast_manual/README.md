# Данные, собранные вручную через VPN РФ

> Часть российских источников (SPIMEX, ФТС, Росстат) недоступны с не-РФ IP — TLS-блок,
> Cloudflare-блок или мёртвые feeds. Эти данные собираются вручную через VPN РФ
> по аналогии со сборкой RAG-корпуса (`scripts/fetch_corpus_manual.sh`).

## Формат CSV

Все файлы — UTF-8 CSV с заголовками. Минимально:

```
date,value
2021-05-06,5180.0
2021-05-07,5215.4
...
```

Опциональные дополнительные колонки (если источник их даёт):

```
date,value,volume,unit,note
```

- `date` — ISO 8601 (`YYYY-MM-DD`).
- `value` — цена, float (точка как десятичный разделитель).
- `unit` — если в файле, единица измерения (`RUB/1000m3`, `USD/1000m3` и т.п.).

## Файлы

| Файл | Источник | Гранулярность | Покрытие |
|---|---|---|---|
| `spimex_gas_<index>.csv` | СПбМТСБ — биржевой индекс цен газа | daily | желательно 2021-05 → наст. |
| `<other>.csv` | альтернативные источники, если SPIMEX выдаст не всё | — | — |

## Манифест

Каждый файл регистрируется в `data/metadata/manifest_gas_manual.yml` (создаётся
после первой загрузки) — ID, источник, URL, дата сборки, sha256, columns,
заметки. Это нужно для reproducibility и review: проверяющий ТЗ должен
понимать что за данные и откуда.

## Что НЕ кладём сюда

- Сырые HTML-страницы или скриншоты — только распарсенный CSV.
- Интерактивные XLSX с merge-cells и форматированием — конвертировать
  в плоский CSV или открыть отдельным fetcher'ом (если стоит того).
- Данные с грифом или по подписке.
