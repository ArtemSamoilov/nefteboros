## Обоснование достаточности набора

Корпус собран **от taxonomy вопросов пользователя** — топ-менеджмента Сбера, кредитующего нефтегазовый сектор РФ. Не «качаем всё, что доступно», а «закрываем восемь категорий вопросов с измеримой полнотой».

### Taxonomy вопросов → источники

| # | Категория вопроса | Пример | Где ищет агент |
|---|---|---|---|
| **A** | РФ-операционка крупных компаний | «Сколько Газпром добыл газа в 2024? Куда экспорт?» | Газпром AR + Accounting, Роснефть AR + IFRS, Лукойл AR, Новатэк AR, Татнефть AR (Блок 2) |
| **B** | РФ-госфинансы и нефть | «Реалистична ли цена Brent $70 в основе бюджета 2026?» | Минэк СЭР 2026-2028, Энергостратегия РФ-2050 (Блок 1) |
| **C** | Санкции и геополитика | «Как работает price cap? Что с Ираном сейчас?» | Bruegel WP 32/2025, REPowerEU progress, CRS Iran×2 (Блок 4) |
| **D** | Краткосрочные цены и балансы | «Прогноз Brent до конца 2026?» | IEF MOMR Comparative, IEA OMR free, EIA STEO, IEA GMR Q1 (Блок 3) **+ price tools** |
| **E** | Долгосрочная стратегия и сценарии | «Пик нефти — когда?» | OPEC WOO 2025, IEA Oil 2025, IEA Gas 2025, ИНЭИ, Энергостратегия (Блок 1) |
| **F** | Глобальные балансы | «Что говорит ОПЕК+ про квоты?» | IEF MOMR Comparative, OPEC AR + ASB, EI Stat Review (Блоки 1, 3) |
| **G** | Газовый рынок (отдельная половина задачи) | «TTF цены сейчас? Арктик СПГ-2 статус?» | IEA Gas 2025, IEA GMR Q1, GIIGNL, Газпром, Новатэк, REPowerEU |
| **H** | Корпоративные micro-новости | «Дивиденды Лукойла в этом году?» | AR компаний (база) **+ web-search в runtime** для свежих |

Категории A, B, C, E, F, G покрываются **полностью из корпуса**. D частично (свежие цены — через price-tools API, не PDF). H частично (текущие события — runtime web-search).

### Покрытие 5 демо-сценариев ТЗ

ТЗ требует продемонстрировать 5 типов взаимодействия. Каждый — поддерживается:

| Демо-сценарий ТЗ | Что включается | Готовность корпуса |
|---|---|---|
| **1. Ответ из отчёта** («Каков прогноз спроса на нефть к 2030 от OPEC?») | RAG → OPEC WOO 2025 | ✅ полностью |
| **2. Ответ из веба** («Что российская нефтяная отрасль добыла в апреле 2026?») | Web-search tool (отдельный PR) | ✅ корпус не нужен |
| **3. Комбинированный** («Как Иран влияет на Brent сейчас?») | RAG (CRS Iran×2 + IEF MOMR) + web-search для свежих событий | ✅ |
| **4. Прогноз цены** («Прогноз Brent до конца 2026?») | Forecast tool (price-tools PR) + RAG (EIA STEO + IEA OMR + ИНЭИ для факторов) | ✅ корпус даёт интерпретационный контекст |
| **5. Вне компетенции** («Расскажи про криптовалюты») | Intent classifier отказывает до RAG | ✅ корпус не задействован |

### Баланс языков (нацеленный 50/50)

По числу документов: **RU 10 / EN 15** = 40/60.
По объёму страниц: ≈ **870/1270 ≈ 41/59**.

Не идеальные 50/50, как договаривались с Артёмом, но близко. **Причина:** глобальные источники (OPEC, IEA, EIA) физически больше по числу разных документов, но российская часть **плотнее по уникальности** — без замены: Энергостратегия, ИНЭИ, Минэк, AR пяти компаний — нет аналогов в EN-источниках. На retrieval-стороне это компенсируется метаданными `language` в чанках и приоритетом RU-контекста при русскоязычных запросах.

### Баланс энергоносителей (нефть + газ)

| Фокус | Документы | Ключевые источники |
|---|---:|---|
| **Чисто нефть** | 13 | OPEC WOO/AR/ASB, IEA Oil 2025, EIA STEO, IEF MOMR, IEA OMR free, Лукойл/Татнефть/Роснефть AR + IFRS, Bruegel WP, CRS×2 |
| **Чисто газ** | 4 | IEA Gas 2025, IEA GMR Q1, GIIGNL, REPowerEU |
| **Mixed (нефть + газ)** | 8 | Энергостратегия РФ, ИНЭИ, Минэк, EI Stat Review, Газпром AR + Accounting, Новатэк AR (СПГ-фокус) |

Газ покрыт через 12 источников (4 чисто + 8 mixed) = ~48% корпуса. Это адекватно: газ — половина задачи «нефтегазового аналитика», и хотя «флагманов» (типа OPEC WOO для нефти) меньше, mixed-документы дают сильный газовый блок.

### Чем закрываются неизбежные пробелы корпуса

| Пробел корпуса | Чем компенсируется |
|---|---|
| Свежесть цен и спот-котировок | `price-tools` API (Brent/WTI/Urals — yfinance + Минфин РФ; Henry Hub/TTF — yfinance/EEX) — отдельный PR |
| Свежие новости (дни/недели) | `web-search` tool в runtime (Brave + whitelist tier-1 RU/EN) — отдельный PR |
| Узкие отраслевые темы (нефтехимия, нефтесервис) | Web-search + intent классификатор «честно скажи если не знаю» |
| Аналитика инвест-банков (SberCIB / VTB Cap / Альфа) | Закрыто для клиентов, не используем |

## Блок 1 — Стратегии и видения (10 документов)

> **Lifecycle:** обновление 1-5 лет. Низкочастотные документы для long-term вопросов и понимания целей/сценариев.

### 1.1 Энергетическая стратегия Российской Федерации до 2050 года
**Издатель:** Правительство РФ · **Дата:** 12.04.2025 (Распоряжение № 908-р) · **Язык:** RU · **Размер:** 1.0 МБ
Целевой долгосрочный документ Правительства РФ — задаёт показатели добычи, экспорта, инвестиций и структурных сдвигов в нефтегазовом секторе на трёх этапах (до 2030, 2031-2035, 2036-2050). Это «официальный план», на который ориентируются все РФ-компании сектора. Главный источник для вопросов вида «Какие цели у государства по [направление] к [год]?»

### 1.2 ИНЭИ РАН — Прогноз развития энергетики мира и России 2024
**Издатель:** ИНЭИ РАН · **Дата:** 2024 · **Язык:** RU · **Размер:** 12.0 МБ
Главный российский научно-академический долгосрочный прогноз энергетики мира и РФ до 2050 года в трёх сценариях. Покрывает нефть, газ, уголь, ВИЭ, электроэнергетику, эмиссии — комплексно. Комплементарен Энергостратегии РФ: Энергостратегия — целевая, ИНЭИ — аналитическая.

### 1.3 Минэкономразвития — Прогноз СЭР 2026-2028
**Издатель:** Минэкономразвития РФ · **Дата:** 26.09.2025 · **Язык:** RU · **Размер:** 1.1 МБ
Официальный среднесрочный макропрогноз — цены нефти Urals/Brent в основе бюджета РФ, курс рубля, ВВП, инфляция, нефтегаздоходы. Ключевой документ для финансовых моделей, на нём строится федеральный бюджет 2026-2028 годов. Главный источник для категории B (госфинансы и нефть).

### 1.4 OPEC World Oil Outlook 2025
**Издатель:** OPEC · **Дата:** 2025 · **Язык:** EN · **Размер:** 13.4 МБ
Главный долгосрочный прогноз OPEC до 2050 года — производительская перспектива на спрос, предложение, инвестиции, технологический микс. Контрапункт IEA Oil 2025 (потребительская перспектива): на одни и те же годы они часто дают разные цифры по пику спроса, и сама эта разница ценна для агента. Скачано вручную после бесплатной регистрации на publications.opec.org.

### 1.5 OPEC Annual Report 2024
**Издатель:** OPEC · **Дата:** 2024 · **Язык:** EN · **Размер:** 3.0 МБ
Годовой отчёт OPEC — рыночный обзор, политика OPEC+, ключевые тезисы за год по балансам, ценам, добыче, экспорту. Короче WOO, но даёт «итоги года» в форме нарратива (полезно для retrieval-вопросов «что было главным в 2024?»).

### 1.6 OPEC Annual Statistical Bulletin 2024
**Издатель:** OPEC · **Дата:** 2024 · **Язык:** EN · **Размер:** 6.9 МБ
Reference book — исторические серии по странам OPEC и не-OPEC: добыча, экспорт, запасы, мощности, цены, доходы. Аналог EI Statistical Review со стороны OPEC, с упором на цифры производителей. Используется для вопросов «какие исторические объёмы у [страна]» и для контекста при сравнении сценариев WOO.

### 1.7 IEA Oil 2025 — Analysis and Forecast to 2030
**Издатель:** IEA · **Дата:** 2025 · **Язык:** EN · **Размер:** 5.0 МБ
Среднесрочный (5-летний) прогноз нефтяного рынка от IEA. Единственный полный нефтяной отчёт IEA в open-access — ежемесячный OMR за paywall с 2020 года. Содержит прогноз спроса, предложения, торговли, refining margins, capex по регионам.

### 1.8 IEA Gas 2025 — Analysis and Forecasts to 2030
**Издатель:** IEA · **Дата:** 2025 · **Язык:** EN · **Размер:** 7.0 МБ
Среднесрочный прогноз глобального газового рынка от IEA — балансы по регионам, СПГ-потоки, политика, сценарии для Европы и Азии. Один из двух газовых «флагманов» в нашем корпусе вместе с GIIGNL (СПГ-фокус). Покрывает категории E, G, F.

### 1.9 GIIGNL World LNG Report 2025
**Издатель:** GIIGNL (International Group of LNG Importers) · **Дата:** 10.06.2025 · **Язык:** EN · **Размер:** 5.9 МБ
Главный отраслевой отчёт по СПГ — глобальные торговые потоки, импортёры/экспортёры, terminals, контрактная структура (long-term vs spot). Critical-источник для российского контекста (Новатэк = ключевой РФ-СПГ-игрок) и для вопросов про замещение российского трубопроводного газа в Европе.

### 1.10 REPowerEU — 3 years on (COM(2025) 637 final)
**Издатель:** European Commission · **Дата:** 08.10.2025 · **Язык:** EN · **Размер:** 2.6 МБ
Официальный отчёт Еврокомиссии о ходе отказа ЕС от российских fossil fuels. Зависимость EU от российского газа упала с 45% (до войны) до 12% в 2025 — это «главный риск» для финмодели Газпрома, без понимания которого невозможно говорить про будущее российского газового экспорта. Покрывает категории C (геополитика) и G (газ) одновременно.

## Блок 2 — Корпоративная картина РФ (7 документов)

> **Lifecycle:** обновление 1 год (annual reports + IFRS/РСБУ). Источник для финансовых вопросов и операционки конкретных компаний. Все 5 компаний — крупнейшие кредит-клиенты Сбера в нефтегазовом секторе.

### 2.1 Газпром — Годовой отчёт 2024
**Издатель:** ПАО «Газпром» · **Дата:** 2025 · **Язык:** RU · **Размер:** 8.9 МБ
Годовой отчёт крупнейшего российского газового игрока — производство (газ/конденсат/нефть), поставки по направлениям (ЕС/Турция/Китай/СНГ), инфраструктурные проекты (Сила Сибири / Сила Сибири 2 / Восточный газ). Скачан вручную через VPN РФ — gazprom.ru блокирует rapid curl с не-РФ IP.

### 2.2 Газпром — Бухгалтерская (РСБУ) отчётность 2024
**Издатель:** ПАО «Газпром» · **Дата:** 2025 · **Язык:** RU · **Размер:** 4.5 МБ
Финансовая отчётность по РСБУ — единственный финансовый источник по Газпрому, поскольку компания не публикует МСФО с 2022 года. Содержит баланс, отчёт о финрезультатах, комментарии. Достаточно для основных финансовых вопросов; полная МСФО-картина недоступна — это явное ограничение.

### 2.3 Роснефть — Годовой отчёт 2024
**Издатель:** ПАО «НК Роснефть» · **Дата:** 30.06.2025 · **Язык:** RU · **Размер:** 22.2 МБ
Самый большой документ в корпусе. Крупнейший российский нефтяной добытчик — подробная операционка, инвестпроекты (Восток Ойл — флагманский upstream-проект РФ, Роспан), стратегия, ESG. Утверждён Общим собранием акционеров 30.06.2025.

### 2.4 Роснефть — Консолидированная МСФО за 12 месяцев 2024
**Издатель:** ПАО «НК Роснефть» · **Дата:** 2025 · **Язык:** RU · **Размер:** 2.0 МБ
Полная финансовая картина по МСФО — P&L, баланс, cash flow, примечания. **Опровергает популярный тезис** «Роснефть не публикует МСФО post-2022» — публикует, и аккуратно. Это ценно: позволяет агенту делать сопоставимый финансовый анализ Роснефти и Лукойла.

### 2.5 Лукойл — Годовой отчёт 2024
**Издатель:** ПАО «Лукойл» · **Дата:** 2025 · **Язык:** RU · **Размер:** 1.8 МБ
Второй по размеру российский нефтяник (по выручке) — сильный downstream (НПЗ в РФ + Европа), история стабильных дивидендов, частный capital allocation в отличие от госкомпаний. Полная МСФО + операционка. Источник для вопросов «как структурирован downstream российских игроков».

### 2.6 Новатэк — Годовой отчёт 2024
**Издатель:** ПАО «Новатэк» · **Дата:** 12.02.2025 · **Язык:** RU · **Размер:** 12.6 МБ
Главный российский СПГ-игрок — Ямал СПГ (флагман), Арктик СПГ-2 (вторая очередь под санкциями США с ноября 2023), Мурманский СПГ (планы). Стратегия диверсификации экспорта на фоне санкционных ограничений. Без этого документа невозможно ответить ни на один вопрос про российский СПГ.

### 2.7 Татнефть — Годовой отчёт 2024
**Издатель:** ПАО «Татнефть» им. В.Д. Шашина · **Дата:** 09.04.2025 · **Язык:** RU · **Размер:** 1.9 МБ
Региональный игрок (Татарстан), пример «средней» нефтяной компании РФ с крепким downstream (комплекс ТАНЕКО — современный НПЗ). Образует нижний ярус peer-comparison для Лукойла/Роснефти. Не критичен для большинства вопросов, но даёт отдельный кейс «не-госкомпания, не-supermajor».

## Блок 3 — Operational срез глобального рынка (5 документов)

> **Lifecycle:** обновление 1-3 месяца. Самые свежие данные о мировом нефтегазовом рынке. **Архив monthly-документов глубже одного номера в RAG не берём** — за свежие новости отвечает web-search в runtime.

### 3.1 IEF Comparative Analysis of Monthly Oil Reports — April 2026
**Издатель:** International Energy Forum · **Дата:** Апрель 2026 · **Язык:** EN · **Размер:** 3.6 МБ
Уникальный документ: сравнительный анализ **OPEC MOMR + IEA OMR + EIA STEO в одном файле** за апрель 2026. Содержит ключевые таблицы балансов, прогнозов, разницы между тремя источниками с комментарием. Заменяет недоступные напрямую OPEC MOMR (за Cloudflare-стеной) и даёт три взгляда сразу — даже информативнее, чем брать MOMR отдельно.

### 3.2 IEA Oil Market Report — April 2026 (free version)
**Издатель:** IEA · **Дата:** 14.04.2026 · **Язык:** EN · **Размер:** 3.1 МБ
Бесплатная версия IEA OMR — full version за paywall с 2020 ($11k/год). Free содержит ключевые балансы и тезисы IEA на текущий месяц. Дополняет IEF Comparative прямой IEA-перспективой.

### 3.3 IEA Gas Market Report Q1-2026
**Издатель:** IEA · **Дата:** Q1 2026 · **Язык:** EN · **Размер:** 4.0 МБ
Свежий operational digest по глобальному газовому/СПГ рынку — балансы регионов, цены TTF/JKM/Henry Hub, потоки СПГ, прогноз на 2026. Газовый аналог OPEC MOMR — закрывает дыру операционного газового среза, которой не было в первоначальном плане.

### 3.4 EIA Short-Term Energy Outlook — April 2026
**Издатель:** U.S. Energy Information Administration · **Дата:** Апрель 2026 · **Язык:** EN · **Размер:** 4.7 МБ
Краткосрочный прогноз цен / добычи / потребления нефти и газа на 12-18 месяцев. US-фокус (Henry Hub, US shale, US refineries), но global summary тоже. Используется в категории D (краткосрочные цены).

### 3.5 Statistical Review of World Energy 2025 (74-е издание, EI/KPMG)
**Издатель:** Energy Institute (in collaboration with KPMG) · **Дата:** 26.06.2025 · **Язык:** EN · **Размер:** 5.4 МБ
Reference book #1 в индустрии — исторические серии 1965+ по добыче, потреблению, торговле, ценам, запасам по всем странам и всем энергоносителям. Бывший BP Statistical Review, с 2023 — под кураторством Energy Institute. Источник для исторических вопросов («когда был пик добычи Х в стране Y», «какая доля газа в энергобалансе Z»).

## Блок 4 — Геополитика и санкции (3 документа)

> **Lifecycle:** обновление 6-12 месяцев. Тематические обзоры think tanks и Congressional Research Service. Критично для категории C (санкции/геополитика) — без этого блока агент не сможет связно объяснить трансформацию российского экспорта и premium на цены от ближневосточных рисков.

### 4.1 Bruegel Working Paper 32/2025 — Russian Oil Price Cap and Embargo
**Издатель:** Bruegel (European think tank) · **Дата:** 18.12.2025 · **Язык:** EN · **Размер:** 1.0 МБ
Глубокий анализ G7 oil price cap и EU embargo на российскую нефть — эффективность, эволюция от $60 (декабрь 2022) к $47.60 (сентябрь 2025), механизм автокоррекции для EU. Один из самых цитируемых аналитических обзоров по теме в Европе. Покрывает вопросы «как работает price cap», «насколько он эффективен», «что с обходом через shadow fleet».

## Что НЕ вошло — сознательные исключения

Не «забыли», а **отказались по дизайну**:

### Глобальные мейджоры (Saudi Aramco, Shell, ExxonMobil, BP, Chevron)
**Почему нет.** Артём чётко обозначил: «отталкиваемся от полезности, а не от перегруженности». Эти компании — конкуренты/партнёры российских клиентов Сбера, а не сами клиенты. Их корпоративная история не нужна. Глобальный взгляд на отрасль покрывается через OPEC WOO + OPEC AR/ASB + IEA Oil 2025 + IEA Gas 2025 + GIIGNL — без необходимости тащить annual reports каждой supermajor отдельно.

### Архив monthly-документов глубже одного номера
**Почему нет.** OPEC MOMR / EIA STEO / IEA OMR / IEA GMR — обновляются ежемесячно или ежеквартально. Годовалые номера устаревают по балансам и квотам. Глубокий архив создаёт **retrieval-шум** при дубликатах похожих формулировок. За свежие новости отвечает `web-search` в runtime.

### Платные подписки (Wood Mackenzie / Rystad Energy / S&P Platts / Argus / Refinitiv / Cedigaz)
**Почему нет.** Open-access only. Платные источники недоступны для воспроизводимости (ревьюеру / у проверяющего их нет), а сам факт оплаченной подписки в учебном проекте — анти-паттерн.

### CSIS Iran HTML articles
**Почему нет.** CSIS публикует тематические обзоры только как HTML-статьи (не PDF). Для RAG нужны структурированные документы. Заменены на **CRS reports** — институциональнее (для Конгресса США), цитируемее, в стандартной PDF-форме.

### Vygon Consulting
**Почему отложено.** Их публикации защищены WAF от curl, скачиваются только через браузер и нерегулярно. Не блокирует RAG: российская сторона уже плотно покрыта (ИНЭИ + Минэк + AR пяти компаний + Энергостратегия). Можно вернуться точечно после `feature/eval-rag`, если появится конкретный пробел.

### Минфин РФ — Основные направления бюджетной политики
**Почему нет.** Дублирует **Минэк СЭР** в части цен нефти и нефтегаздоходов. При retrieval два похожих чанка из разных документов конкурируют — лишний шум. Минэк шире (макро + цены + бюджет), Минфин уже — оставляем один документ.

### МСФО Газпрома post-2022
**Почему нет.** Компания не публикует. Используем РСБУ (`gazprom_accounting_2024.pdf`) как единственный финансовый источник по Газпрому. Это неустранимое ограничение реальности, не наш недосмотр — отметим в README ассистента.

## Известные ограничения

| Ограничение | Митигация |
|---|---|
| **IEA OMR full** — paywall с 2020 ($11k/год) | Используем `iea_omr_2026-04_free.pdf` (короткая free version) + IEF Comparative |
| **OPEC WOO** — требует одноразовой бесплатной регистрации | Скачано вручную; в манифесте `fetch_note` объясняет |
| **OPEC MOMR** — Cloudflare challenge | Заменён на IEF Comparative Analysis (3 источника в одном) |
| **CSIS Iran** — только HTML | Заменены на CRS PDF reports |
| **Vygon** — WAF блок curl | Опционально вручную, не критично для v1 |
| **Газпром МСФО post-2022** | Используем РСБУ-версию; полный P&L по МСФО недоступен |
| **Российские сайты SSL timeout с не-РФ IP** | Часть документов (Газпром AR, Минэк, Татнефть в первой попытке) собрана через VPN РФ — `scripts/fetch_corpus_manual.sh` |
| **Свежесть** — Минэк СЭР (сент. 2025), MOMR/STEO (апр. 2026) | На момент сборки — самые свежие; обновляем при выходе новых выпусков |

## Lifecycle и обновления

| Триггер | Действие |
|---|---|
| Вышел новый MOMR / STEO / GMR / OMR | Заменить старый файл, пересчитать sha256, обновить manifest и пройти `python scripts/fetch_corpus.py --check` |
| Новый ИНЭИ Прогноз / IEA Oil / IEA Gas / WOO | Добавить как новый документ в манифест, **сохранить старый ещё на 1 год** для сравнения сценариев |
| Новый годовой отчёт компании | Заменить старый AR + IFRS на свежий |
| Изменилась стратегическая обстановка (новые санкции / новый этап Энергостратегии) | Добавить тематический документ в Блок 4 |
| Обнаружился пробел в категории вопросов после `feature/eval-rag` | Точечно добавить документ; не наращивать корпус «на всякий случай» |

**Бюджет на обновление:** ручка в манифесте + повторный `fetch_corpus.py` ≈ 10 минут.
