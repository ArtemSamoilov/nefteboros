# ADR-0029 — Self-reflection: advisory саморазвитие без самомодификации

- Статус: accepted
- Дата: 2026-05-25
- Связано: ADR-0001 (fork-ouroboros), ADR-0024 (observability-langfuse),
  ADR-0027 (eval-dialogue-isolation), changelog 2026-05-04-rip-self-modify,
  прецедент advisory-ревью (`ouroboros/tools/claude_advisory_review.py`)

## Контекст

ТЗ Сбера требует, чтобы агент строился на Ouroboros и **обоснованно назывался
саморазвивающимся**. При этом в v1.0.0 подсистемы самомодификации Ouroboros
(`consciousness.py`, `reflection.py`, `deep_self_review.py`,
`improvement_backlog.py`) **намеренно выпилены** (см. changelog
2026-05-04-rip-self-modify): для ассистента-аналитика, работающего с финансовыми
данными, самомодификация кода/промпта — неприемлемый риск (агент, переписывающий
собственную логику прогноза цен или системный промпт без ревью).

Возникает противоречие: ТЗ хочет «саморазвивающийся», а безопасность запрещает
самомодификацию. Нужен механизм, снимающий это противоречие, а не сглаживающий
его компромиссом.

## Решение

**Различение, снимающее риск: саморазвитие через РЕФЛЕКСИЮ ≠ самомодификация
КОДА.** Возвращаем только рефлексию (агент анализирует свою работу и *предлагает*
улучшения) и НЕ возвращаем самомодификацию (агент НЕ переписывает себя). Этого
достаточно, чтобы честно называться саморазвивающимся, без риска.

Ouroboros-цикл (самореференция) в advisory-форме, переиспользующий observability
(ADR-0024, починена в PR #78):

```
наблюдение (трейсы взаимодействий)        ← READ-ONLY
   → рефлексия (LLM поверх паттернов своих ответов)
      → improvement backlog (структурные предложения)
         → [человек ревьюит и решает]      ← петля замыкается ЧЕЛОВЕКОМ
```

Реализация — пакет `nefteboros/self_reflection/` + CLI `scripts/self_reflect.py`:

- **Двухслойная рефлексия.** (1) Детерминированные детекторы считают РЕАЛЬНЫЕ
  сигналы из трейсов без LLM: error-rate, горячие узлы-источники ошибок,
  latency/cost-перцентили, refusal-rate, citation-rate, структурные прокси
  (synthesize без инструмента; synthesize без `validate_citations`).
  (2) LLM синтезирует из сигналов + выборки трейсов конкретные advisory-находки.
  LLM — первичный; при его недоступности graceful-откат на детерминированные
  heuristic-items. Оба пути дают РЕАЛЬНЫЙ вывод, не заглушку.
- **Триггер — CLI**, не каждый запрос (стоимость/латентность). Опционально может
  вешаться на cron/раз в N сессий — инфраструктуру для этого НЕ строим (вне scope).
- **Выход** — `data/self_improvement/backlog.jsonl`: structured-записи
  (`date, observation, suggestion, evidence_trace_id, severity, category,
  source, fingerprint, status, applied`). Dedup по fingerprint.
- **Env-флаг `OUROBOROS_SELF_REFLECTION` (default OFF).** Гейтит CLI `run`; прод
  (путь ответа агента) от рефлексии не зависит вообще.

Это согласуется с уже существующим в кодовой базе паттерном advisory-ревью
(`claude_advisory_review.py`): LLM предлагает находки → человек решает → ничего не
применяется само. Self-reflection — тот же принцип, применённый к рантайм-трейсам
агента, а не к git-диффу.

## Почему НЕ auto-apply

Агент НЕ применяет свои предложения сам — человек в петле. Это осознанная
safety-граница, а не недоделанность:

- Ассистент работает с финансовыми данными (прогноз цен, цитирование источников).
  Автоприменённое «улучшение» промпта/логики может тихо исказить прогноз или
  цитаты — и проявиться поздно, на проде, у пользователя уровня топ-менеджмента.
- `BacklogEntry.applied` всегда `False`. Ни одна функция в кодовой базе не читает
  backlog обратно в контекст агента и не выставляет `applied=True` (есть тесты,
  гарантирующие это статически — по AST).
- На защите это **сильный пункт**, а не слабость: «агент саморазвивается, но
  граница самомодификации проведена сознательно — предложения проходят через
  человека».

## Почему НЕ самомодификация кода/промпта

Не возвращаем `consciousness` (фоновая нитка, переписывающая себя),
`deep_self_review` (слэш-команда саморевью с правками), `reflection._update_patterns`
(самообновление паттернов в контекст). Рефлексия здесь **только предлагает** —
строкой в backlog, которую читает человек. Выпиленный `improvement_backlog.py`
переиспользован частично: сохранён принцип «advisory + dedup по fingerprint +
provenance», но вырезаны (а) markdown-формат и (б) `format_backlog_digest`,
который инжектил backlog в контекст агента (см. ниже про изоляцию).

## Изоляция от analyst-пути (урок ADR-0027)

ADR-0027 показал: инжект глобальной истории (`data/logs/chat.jsonl` через
`context.py::build_recent_sections`) в контекст КАЖДОЙ задачи раздувал контекст и
вызвал хвостовой timeout в eval. Выпиленный `format_backlog_digest` делал ровно
то же — инжектил backlog-дайджест в контекст. **Этот механизм НЕ воссоздаётся.**

Гарантии изоляции (закреплены тестами `tests/test_self_reflection.py`):

- Рефлексия читает трейсы **READ-ONLY** (`metrics/runs/*/trace.jsonl` или Langfuse)
  и пишет в **ОТДЕЛЬНЫЙ** backlog. Никакого касания `chat.jsonl`,
  analyst-контекста, пути retrieval→forecast→synthesize.
- Пакет `self_reflection` НЕ импортирует `nefteboros.graphs`, `ouroboros.context`,
  `ouroboros.agent`, `ouroboros.consolidator` (проверка по AST-импортам).
- Прод-код агента (`server.py`, `ouroboros/*`, `nefteboros/graphs/*`,
  `nefteboros/observability/*`) НЕ импортирует `self_reflection` — backlog не
  читается обратно в контекст (проверка сканированием).
- Фоново/по-команде, graceful: ошибка рефлексии (нет LLM-ключей, сеть, битый
  трейс) НЕ влияет на ответы агента — как observability самоотключается без ключей.

## Нарратив саморазвития (для защиты)

Агент **наблюдает себя** (свои трейсы), **рефлексирует** над паттернами своих
ответов (ложные отказы, слабые/отсутствующие цитаты, ошибки узлов, пробелы
покрытия) и **формулирует предложения по улучшению самого себя**. Это
самореференция — суть Ouroboros (змея, кусающая свой хвост). Отличие от
«полного» Ouroboros — петля замыкается не автоприменением, а ЧЕЛОВЕКОМ. Для
доменного ассистента это не урезание, а корректная инженерная граница:
саморазвитие реально (механизм работает на mock + демо-примерах, не заглушка),
а риск самомодификации снят.

## Источники трейсов: богатство и честность

- **JSONL (первичный, всегда доступен).** Live JSON-tracer НЕ хранит текст ответа
  (усекает до compact-метаданных, см. `tracer.py`). Поэтому из локального JSONL
  доступны **структурные** сигналы (узлы/статусы/latency/cost/query) и структурные
  прокси по цитатам/покрытию, но НЕ контентные детекторы по тексту ответа.
- **Langfuse (best-effort, если заданы ключи).** `@observe` auto-capture хранит
  полный input/output → добавляет **контентные** сигналы (refusal/citation по
  тексту). На любой сбой — graceful откат на JSONL.

Это честное свойство, не баг: глубина рефлексии растёт с богатством наблюдаемости.
Демо (`examples/self_reflection/`) показывает оба уровня на контент-богатых
sample-трейсах (репрезентативные ответы из eval-фикстур проекта).

## Последствия

- Агент обоснованно называется саморазвивающимся: рабочий рефлексивный цикл,
  переиспользующий observability, с durable advisory-backlog'ом.
- Прод не затронут и не зависит от рефлексии (флаг OFF, отдельный модуль/выход).
- Появляется durable-канал для накопления самонаблюдений между сессиями — основа
  для будущего (если когда-то понадобится) more-active цикла, но под ревью.

## Не в scope (бэклог)

- **Auto-apply** предложений — сознательно не делаем (safety-граница).
- **Самомодификация** кода/промпта; возврат `consciousness`/`deep_self_review`.
- **Per-request** рефлексия (стоимость/латентность) — только по команде.
- **Cron / раз в N сессий** — точка расширения, инфраструктуру не строим.
- **Semantic dedup** backlog'а (сейчас dedup по точному fingerprint
  observation+suggestion+category) — допустим лёгкий churn near-duplicate'ов между
  прогонами; для advisory-backlog'а под ревью человека это приемлемо.

## Альтернативы (отвергнутые)

- **Вернуть полный Ouroboros-цикл с самомодификацией.** Неприемлемый риск для
  фин-ассистента (см. changelog 2026-05-04-rip-self-modify) — отвергнуто.
- **Чистый LLM-анализ без детерминированных детекторов.** Менее честно и хуже
  демонстрируется: без ключей/сети рефлексия превращалась бы в заглушку.
  Детекторы дают реальный вывод всегда; LLM обогащает — отвергнуто в пользу
  гибрида.
- **Инжект backlog-дайджеста в контекст агента** (как выпиленный
  `format_backlog_digest`). Повтор дефекта ADR-0027 (рост контекста → timeout) и
  размытие границы «человек в петле» — отвергнуто.
